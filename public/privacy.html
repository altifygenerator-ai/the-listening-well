Privacy

Last updated: August 21, 2026. Throw a Penny is designed so a wish stays private unless you choose to share an echo.

Private by default

Wishes are stored on the visitor’s device unless cloud storage is configured. Share cards contain only the generated echo, not the original wish.

AI processing

When an AI provider is connected, wish text and any optional clarification you provide are sent to the server and then to that provider to create a response and perform safety screening. API keys are never exposed to the browser.

Cloud storage

When Supabase is connected, wishes, optional clarifying details, generated responses, and Moon notes may be stored under a random anonymous session identifier so they can be recovered by the same browser. Account-based storage can be added later.

Payments

Payments are processed by Stripe when enabled. The site does not store full card numbers.

Control

Visitors can export or clear the journal from the Journal panel. When cloud storage is connected, clearing also requests deletion of the anonymous cloud profile and its wishes.
